# Budss — платёжная платформа для роста бизнеса

Официальный сайт платёжной платформы Budss: решения для привлечения и удержания клиентов с помощью бесконтактных платежей, аналитики и программ лояльности.

## Демо

[Ссылка на демо‑версию](https://ваш-сайт.com) *(замените на реальную ссылку после деплоя)*

## Обзор проекта

Веб‑сайт Budss представляет собой лендинг для продвижения платёжного сервиса, ориентированного на бизнес.

**Ключевые особенности:**
* адаптивный дизайн (мобильные и десктопные устройства);
* интерактивное мобильное меню‑бургер;
* форма обратной связи для связи с отделом продаж;
* визуализация преимуществ продукта (аналитика, защита от мошенничества, NFC‑платежи и т. д.);
* интеграция с социальными сетями и маркетплейсами;
* модальные окна для форм и уведомлений;
* cookie‑баннер с согласием на использование файлов cookie.

## Основные разделы сайта

* **Шапка (Header)**: навигация для бизнеса и клиентов, логотип, кнопка «Contact sales», мобильное меню.
* **Главный экран**: слоган «Everyone is an Influencer», описание сервиса, кнопка связи с отделом продаж.
* **О Budss (About)**: описание сервиса, преимущества (бесконтактные платежи, увеличенная покупательная способность, аналитика, защита от мошенничества).
* **Как это работает (How Budss Works)**: визуализация ключевых показателей роста (15 % увеличение суммы покупки, 30 % рост годовых продаж и т. д.).
* **Почему Budss (Why Budss)**: углублённое описание преимуществ (инфлюенсеры, оптовые покупки, ИИ и геймификация, мгновенный кешбэк).
* **Рост бизнеса (Let Your Business Grow)**: интеграция с соцсетями (Facebook, Twitter, Instagram, TikTok), логотипы партнёров.
* **Футер (Footer)**: логотип, ссылки для бизнеса и клиентов, кнопки загрузки приложений, копирайт.
* **Дополнительные компоненты**: форма связи, окно «Спасибо», баннер согласия на использование cookie.

## Технологии

* **HTML5** — семантическая разметка, структура страницы;
* **CSS3** — стилизация, адаптивный дизайн, Flexbox/Grid‑вёрстка, медиа‑запросы;
* **JavaScript** — интерактивность (мобильное меню, формы, модальные окна, cookie‑баннер);
* **BEM‑методология** — организация CSS‑классов для масштабируемости;
* **Responsive Design** — корректное отображение на всех устройствах.
